# NoevaPet Pre-Deployment V17

## Changes from V16
- Added **Trockenfutter / Dry food** as a first-class Pet Match need.
- Refined the Pet Match need icon family into fuller flat illustrations and reused the same visual language on the six homepage entry cards.
- Added matching sleep and travel illustrations so all six homepage entries feel like one NoevaPet family.
- Reduced the six-entry homepage section height substantially: tighter section spacing, smaller cards, tighter typography and CTA chips.
- Redesigned **Meine Tiere / My pets** when no profile exists: no more “switch pet” headline, saved-pets box hides, and the first-profile form becomes the clear primary action.
